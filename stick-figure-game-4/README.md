# Stick Figure Game 4 (Booby Trap prototype)

Godot **4.x** project. Main scene: `Stick Figure 4.tscn`.

## Play (no editor)

1. Install [Godot 4](https://godotengine.org/download) (4.7.1+ recommended).
2. Double-click **`Play Stick Figure Game 4.bat`**

If the bat cannot find Godot:
- Set environment variable `GODOT_PATH` to your Godot `.exe`, **or**
- Add Godot to PATH as `godot`, **or**
- Open `project.godot` in Godot Project Manager and press F5.

## Open in Godot Editor

Project Manager → Import / Open → select this folder’s `project.godot`.

## Controls (current build)

- **WASD / arrows** — move active player
- **E** — set trap (P1) / use object (P2)
- **I** — inspect (P2 near plant)

See `HANDOFF.md` for full design + structure notes.
