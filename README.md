# Buzz-Repo

Shared workspace for Buzz channel projects.

Each game is a **separate top-level folder** (same granularity). Download or open either folder on its own.

## Stick Figure Game 4

Earlier Godot 4 prototype (booby-trap bedroom baseline).

**Folder:** [`stick-figure-game-4/`](./stick-figure-game-4/)

1. Install Godot 4.x  
2. Open that folder → double-click **`Play Stick Figure Game 4.bat`**  
   **or** open `project.godot` in Godot and press F5  

Details: `stick-figure-game-4/README.md` and `HANDOFF.md` if present.

## Booby Trappin'

Current full game snapshot (anxiety, multi-NPC encounters, office map transition, lizard, etc.).

**Folder:** [`Booby Trappin'/`](./Booby%20Trappin'/)

1. Install Godot 4.x  
2. Open **`Booby Trappin'`** → double-click **`Play Stick Figure Game 4.bat`**  
   **or** open `project.godot` in Godot and press F5  

Both folders are independent playable projects.
